# QWEN-999B Evaluation Reports Directory

This directory stores standardized benchmarking reports generated by [`eval/run_benchmark.py`](../run_benchmark.py).

## Benchmarking Overview

The evaluation suite runs all 20 test prompts from [`eval/test_prompts.json`](../test_prompts.json) across 4 core domains:
1. **Reasoning:** Linguistic trap detection, elimination logic puzzles, Troy vs Avoirdupois units, family relationship counting, and water jug state machines.
2. **Coding:** Kadane's algorithm with index tracking & negative arrays, thread-safe Token Bucket rate limiter, Python closure late binding, binary tree serialization, and median of two sorted arrays in $O(\log(\min(m, n)))$.
3. **Math:** Modular arithmetic via Fermat's Little Theorem, trailing zeros in $250!$ via Legendre's formula, conditional probability of dice sums, infinite power tower convergence limits, and deck of cards expectation.
4. **Hinglish:** PostgreSQL B-Tree vs GIN indexing for JSONB, production memory leak heap dump debugging, Kafka consumer lag & scaling, bitwise XOR single number trick, and Bias-Variance tradeoff with L1 vs L2 regularization.

## Running the Benchmark

```bash
# 1. Run live benchmark against local Ollama instance with default 7B Q4_K_M model
python eval/run_benchmark.py --model qwen2.5:7b-instruct-q4_K_M --host http://localhost:11434

# 2. Run benchmark on trained QWEN-999B checkpoint
python eval/run_benchmark.py --model qwen-999b:latest --host http://localhost:11434

# 3. Dry-run test mode (offline validation without active Ollama server)
python eval/run_benchmark.py --dry-run
```

## Report Files

- `benchmark_<model>_<timestamp>.md`: Full Markdown evaluation report with KPIs, domain breakdown tables, and prompt-by-prompt `<think>` inspection.
- `benchmark_<model>_<timestamp>.json`: Machine-readable performance metrics, latencies, tokens/sec, and scores.
